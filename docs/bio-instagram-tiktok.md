## 📋 Como aplicar

### Instagram

1. Abrir app Instagram → Perfil → **Editar Perfil**
2. Campo "**Bio**": colar a Versão A
3. Campo "**Site**" (link único): `https://garimposp.netlify.app`
4. Salvar

### TikTok

1. Abrir app TikTok → Perfil → **Editar perfil**
2. Campo "**Bio**": colar a Versão A
3. Campo "**Site**" (se já tiver 1k seguidores): `https://garimposp.netlify.app`
4. Salvar
